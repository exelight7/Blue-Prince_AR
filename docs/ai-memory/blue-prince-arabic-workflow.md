Goal: full (100%) professional Arabic localization of Blue Prince (Unity 2021.3.45f1 IL2CPP) at `D:\Games\Blue Prince_AR`; original game `D:\Games\Blue Prince` stays read-only. All testing happens in `runtime_test/` (copy of the game with BepInEx installed).

**Approach (replaced the old asset-repacking attempt):** BepInEx 6 IL2CPP be.791 + custom plugin `plugin/BluePrinceArabic` (Harmony patch on `TMP_Text.ParseInputText`: swap m_text for shaped Arabic, restore after; `StringTypewriter.OnEnter` prefix translates baseString). Arabic is pre-shaped (presentation forms, `Shaper.cs`) in LOGICAL order with TMP `m_isRightToLeft=true`; LTR runs (Latin/digits) are stored reversed. This keeps TMP's native word-wrap correct (verified by screenshot). Alignment Left<->Right flipped per object. Arabic font = game's own NotoNaskhArabic Font turned into a dynamic TMP asset, added as fallback to every font asset.

**Why:** old approach (pre-shaped visual text, TMP RTL off) reversed wrapped lines and could not handle dynamic text.

**How to apply / workflow:**
- Corpus: `tools/build_corpus.py` -> `translation/work/corpus.json` (tiers 0-3 visible, 9 = FSM internal values, only translate if runtime log shows them).
- Translate: `python tools/next_batch.py 150` prints next untranslated; write `translation/arabic/batches/bNNN.json` ({english: arabic}); identity value = intentionally kept English (puzzle words, drop-cap fragments like "ROPHY"). `python tools/merge_batches.py` validates tags/numbers/[KEYS] and writes `translation/arabic/ar.json`.
- Plugin matches exact source, then trimmed, then case-insensitive, then strips outer tags/whitespace; `ar_patterns.json` (regex->replacement) planned for dynamic strings (DAY n, PROFILE n...).
- Run/test: `sh tools/enter_game.sh` (kill, deploy, launch, New Game click, skip intro); `python tools/gamectl.py cmd "shot name" "scan" "set OBJNAME|text"` drives the plugin through `runtime_test/BepInEx/bpar/cmd.txt` (one command per 0.5s poll); screenshots + `untranslated.tsv` land in that folder. Mouse click works for menus; keyboard ENTER must be held (~3s) to skip cutscene.
- Gotchas: Bash tool chokes on heredocs containing some quote/backslash patterns -> use Write/Edit for C#/JSON files. Run python without `-I` when importing local tools. Intro cutscene is a long video (text inside video can't be translated). New-game test writes save data to the user's LocalLow profile.
- Fonts (user asked for game-fitting Arabic fonts): `tools/make_pf_font.py` adds presentation-form cmap entries to Google fonts (TMP does no GSUB shaping); only Amiri, IBM Plex Arabic, Lalezar, Mirza, Katibeh, Rakkas worked (Aref Ruqaa/Jomhuria/Scheherazade/Harmattan lack usable GSUB forms). `Font(path)` loads TTFs fine. Fallbacks must be patched on ALL loaded TMP font assets up front (`ArabicFont.PatchAllLoaded`, every 2s) — patching lazily inside the first parse showed boxes (□) and the user saw it. `gallery` command shows every game font next to its Arabic sample; `scan` prints font asset + style per text. The user watches the same game window and takes their own screenshots — don't kill/redeploy while they are testing without saying so; Escape (hold ~4s) skips the intro, not Enter.
- Current font mapping (ArabicFont.StyleFor): display/menu -> IBM Plex Bold (Lalezar too heavy), typewriter/UI -> Plex Medium, serif/book -> Amiri, hand -> Mirza Bold, blueprint caps (dArchitect) -> Plex Medium (Katibeh overlapped lines), child hand -> Rakkas. Letter page layout: Arabic paragraphs wrap to fewer lines than English, so blank-line runs between a paragraph and separate bullet TMPs need +2 lines (see tools/gen_b008.py). `reload` command needs TextOps cache cleared (done).
- Layout gotchas found from the user's screenshots: (1) game TMP objects use letter spacing/negative leading, which breaks Arabic joins and overlaps lines -> plugin zeroes characterSpacing/lineSpacing/wordSpacing for Arabic and restores them for English; (2) alignment: only Left becomes Right, Right stays Right (menus anchored right otherwise jump left); (3) stacked menu labels use leading/trailing "\n" for position, so lookup must keep outer whitespace (Translator.Resolve: exact -> wrapper(prefix/core/suffix) -> lower); (4) Arabic wraps to fewer lines, so check pages that place separate TMPs below a paragraph.
- BUILD CHECK: tools/deploy_plugin.sh now aborts on compile errors (earlier it silently deployed the old DLL for several rounds because a python-escaped C# edit broke the build). Alignment/fit rule: a box holding one line (rect.height < 2*fontSize, no newline) keeps its alignment and shrinks to fit; paragraph boxes flip Left->Right. Handwriting style (Mirza) is wrapped in <size=85%>. nav helper: tools/nav_controls.py; tools/gamectl.py click works on pause menu items (e.g. 1555,470 = end day).
- Known TODO: drop-cap split item names (letter + remainder in separate TMP), fragments ("and", "is", "to the"), icon-gap sentences, typewriter verification, texture text, `ar_patterns.json`, installer/uninstaller, state/*.md refresh.

## Round 3 (2026-10-29, after the zoom intro was accepted)
